# AOF Game Bot

ربات بازی استراتژیک تلگرام «خاکستر جنگ» (aiogram 3) — لشکرکشی، اعلان جنگ، محاصره و بیانیه رسمی.

Bot: https://t.me/AOF_GAME_BOT

## متغیرهای محیطی (Railway → Variables)

| نام | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather (الزامی) |
| `ADMIN_ID` | آیدی عددی مالک/ادمین |
| `CHANNEL_ID` | کانال اصلی (پست اعزام، محاصره، جنگ) |
| `REPORT_CHANNEL_ID` | کانال گزارش لشکرکشی (آمار برای ادمین). اگر نباشد به پی‌وی ادمین می‌رود |
| `TWEET_CHANNEL_ID` | کانال توییت (بیانیه‌ها). اگر نباشد به کانال اصلی می‌رود |
| `ADMIN_CODE` | کد ورود ادمین؛ پیش‌فرض `ADMIN` |
| `BACKUP_CHAT_ID` | محل پشتیبان داده‌ها؛ پیش‌فرض پی‌وی ادمین |
| `DATA_FILE` | مسیر فایل داده؛ پیش‌فرض `data.json` (با Volume: `/data/data.json`) |

آیدی کانال عددی است و با `-100` شروع می‌شود؛ ربات باید در همه‌ی کانال‌ها ادمین باشد.

## ماندگاری داده‌ها

شهرها، کدها، فرماندهان و دکمه‌های فعال کانال در `DATA_FILE` ذخیره می‌شوند و یک نسخه‌ی پشتیبان هم به‌صورت
فایل پین‌شده در تلگرام (پی‌وی ادمین) نگه داشته می‌شود؛ اگر Railway فایل‌ها را پاک کرد، ربات موقع روشن شدن
از همان پشتیبان بازیابی می‌کند. آن پیام را حذف نکنید.

## عکس پست‌های کانال

فایل‌های `images/campaign.jpg`، `images/war.jpg` و `images/siege.jpg` (یا png) اگر وجود داشته باشند
روی پست لشکرکشی، جنگ و محاصره گذاشته می‌شوند.

## پنل ادمین

با حساب `ADMIN_ID` بعد از `/start` کد `ADMIN` را بفرستید: پیام همگانی، آمار شهرها،
حذف دسترسی بازیکن (کدش باطل می‌شود) و افزودن شهر (کد `AOW…` خودکار ساخته می‌شود).

## اجرا

```
pip install -r requirements.txt
BOT_TOKEN=... python main.py
```

توکن را هرگز داخل کد یا ریپو نگذارید.
